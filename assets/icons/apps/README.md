# App icons

Put transparent PNG app icons here and name each image after the app identifier:

`browser.png`, `files.png`, `notes.png`, `settings.png`, `music.png`, `paint.png`, `cinehub.png`, `store.png`, and `terminal.png`.

The launcher and dock will fall back to bundled SVG icons when PNG files are missing. Do not upload SVG from untrusted sources without sanitizing it.
